# Food Delivery Time Analysis Using Python

## Project Overview
This project analyzes food delivery data to understand delivery times and explore the factors that may affect delivery performance. The goal is to identify patterns in delivery duration using Python, data analysis, and visualization techniques.

## Dataset
- **Total Records:** 45,584
- **Total Columns:** 20
- **Data Type:** Food delivery dataset

The dataset contains information about delivery personnel, weather conditions, traffic levels, vehicle types, city, order type, and delivery time.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Project Workflow
1. Loaded and inspected the dataset.
2. Identified missing values and checked data quality.
3. Cleaned the data and handled missing values.
4. Performed Exploratory Data Analysis (EDA).
5. Analyzed delivery time across different categories.
6. Created visualizations to explore patterns and relationships.
7. Calculated key performance indicators (KPIs).
8. Exported the cleaned dataset to a CSV file.

## Exploratory Data Analysis
The project explores delivery time based on:

## Key Business Questions

- How do weather conditions relate to delivery time?
